# Verilog MAC with Delta-compressed weights (Delta)

This plugin provides different MAC operations implemented in Verilog. 
All implementations distinguish between consecutive and fixed-reference decompression:

- Computing Core for Multiply and Accumulate Operator with Delta-Compressed Weights (MAC_DELTA_CORE)
- Delta-compressed MAC operator for array processing (MAC_DELTA_ARRAY)
- Delta-compressed MAC operator for BRAM processing (MAC_DELTA_BRAM)
