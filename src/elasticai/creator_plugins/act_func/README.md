# Verilog Activation Function for Deep Neural Networks

This plugin provides different modules for building activation functions used in deep neural networks in verilog:

- Activation Functions
  - Absolute
  - HardTanh
  - HardSigmoid (1/4)
  - Heaviside
  - Precomputed (Tanh, Sigmoid, ...)
  - ReLU
  - PReLU
  - Sign
